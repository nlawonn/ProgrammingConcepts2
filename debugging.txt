When building an application, regular debugging is a necessary step. It helps ensure the flow of the program is as intended, by eliminating errors and unexpected output. Errors simply stop the code from running when the program gets to a certain point. Unexpected output can be tricky to troubleshoot because it requires a more focused approach to fix.
Some ways to fix errors I've used are print functions to output certain variables to ensure the program is progressing as expected. While most programs will not be so small, a quick scan of the code could identify a data type or operand that is not correct or other syntax errors.
